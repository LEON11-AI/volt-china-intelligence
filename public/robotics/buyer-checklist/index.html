How to Use This Checklist

Purpose & Evidence Labels

Use it to compare quotations, request missing evidence, and record the questions that must be resolved before a purchase order. The goal is not to find the “best robot” — it is to make the quoted configuration, software access, delivery and support specific enough to approve or hold.

Start With the Experiment

What must your team be able to do on the delivered robot in its first month?

Four-Step Workflow

  1. Write down the exact robot, configuration and software versions being quoted.
  2. Mark each requirement Must-have, Preferred or N/A. Explain any N/A.
  3. Save the supporting document, version, date and responsible person.
  4. Tick a box only when the requirement is resolved for your order.

Evidence Labels

Manufacturer-Confirmed

A traceable written answer for the exact configuration and intended use.

Publicly Documented

An identifiable public source describes the feature; it may cover another configuration or release.

Needs Direct Confirmation

Evidence is missing, incomplete or not yet matched to this order.

Scope Note

Public research edition. Order-specific manufacturer confirmations and physical platform testing are outside this checklist.
